# Example conversations

Each `.md` file in this folder is the transcript of a **real** conversation with the agent: an Anthropic model plus tools over the store's data. The files are generated by [`generate_examples.py`](generate_examples.py) and are not edited by hand. Each turn shows the tools the agent decided to call, with their arguments and results, in a collapsible "🔧 Tools called" block.

**Language:** in these examples the customer writes in English, so reviewers can read them, and the agent answers in English. The agent replies in the customer's language, and its default for the store's real audience is Brazilian Portuguese. The catalog and the policy manual are in Portuguese, so the agent's search terms (e.g. `"category": "Violões"`) and parts of the tool results are in Portuguese. Prices and dates keep the Brazilian format (`R$ 2.199,00`, `24/02/2026`).

## How to regenerate

```bash
uv run python examples/generate_examples.py          # all scenarios
uv run python examples/generate_examples.py 03 04    # only some, by prefix
```

- The store's date and time are pinned to **Friday, 20/02/2026, 10:30**, so deadlines and opening hours are reproducible. On that date, order 7 (scenario 4) was received 3 days earlier.
- No partner store is configured (`PARTNER_STORES` is empty).
- If the API fails on any turn, the scenario is **not saved**, so an incomplete conversation never becomes an example.
- LLM answers vary between runs: the wording changes, but the rules (values, deadlines, scope) come from the tools and should hold.
- Every transcript was checked against the data (prices, installments, deadlines, stock, manual sections) before being committed.
